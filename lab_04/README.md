## Опис завдання

Програма візуалізує гармоніку вигляду `y(t) = A * sin(ωt + φ)`, додає до неї шум, дозволяє змінювати параметри через інтерактивні елементи та фільтрує зашумлений сигнал фільтром Баттерворта.

## Можливості програми

- Побудова початкової гармоніки.
- Додавання шуму з параметрами середнього значення та дисперсії.
- Інтерактивне налаштування амплітуди, частоти, фази, параметрів шуму та частоти зрізу фільтра.
- Чекбокс для ввімкнення або вимкнення відображення шуму.
- Кнопка **Reset** для повернення початкових значень.
- Одночасне відображення чистої, зашумленої та відфільтрованої гармоніки.

## Встановлення

Потрібен Python 3.10 або новіший.

```bash
python -m venv .venv
```

### Windows

```bash
.venv\Scripts\activate
pip install -r requirements.txt
```

### macOS / Linux

```bash
source .venv/bin/activate
pip install -r requirements.txt
```

## Запуск

```bash
python main.py
```

## Як користуватися

1. Запустіть програму командою `python main.py`.
2. Переміщуйте слайдери **Amplitude**, **Frequency** та **Phase**, щоб змінювати параметри гармоніки.
3. Переміщуйте **Noise mean** та **Noise covariance**, щоб змінити параметри шуму. Після зміни цих параметрів шум генерується заново.
4. Змінюйте **Cutoff frequency**, щоб побачити вплив низькочастотного фільтра на зашумлений сигнал.
5. Використовуйте чекбокс **Show noise**, щоб показати або приховати шум на графіку.
6. Натисніть **Reset**, щоб повернути початкові параметри.

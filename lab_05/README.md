# Лабораторна робота №5

## Інформація про студента

- **ПІБ:** Кінаш Єгор
- **Група:** ФБ-44
- **Дисципліна:** ЗПАД
- **Тема:** Обмін результатами та початковий аналіз даних у Streamlit

## Опис проєкту

Цей проєкт містить веб-додаток на Streamlit для початкового аналізу очищеного набору даних з показниками **VCI**, **TCI** та **VHI**. Застосунок дозволяє вибирати показник, область, інтервали років і тижнів, переглядати відфільтровану таблицю та будувати два графіки.

## Структура файлів

```text
lab5_streamlit_app/
├── app.py
├── requirements.txt
├── .gitignore
└── README.md
```

Файл з даними `vhi_cleaned_all.csv` потрібно покласти в цю саму папку перед запуском програми.

## Встановлення залежностей

```bash
pip install -r requirements.txt
```

## Запуск

```bash
streamlit run app.py
```

Після запуску Streamlit відкриє застосунок у браузері.

## Функціональність

- вибір одного з часових рядів: `VCI`, `TCI`, `VHI`;
- вибір області;
- фільтрація за діапазоном років;
- фільтрація за діапазоном тижнів;
- сортування таблиці за вибраним показником;
- вкладка з таблицею відфільтрованих даних;
- лінійний графік для вибраної області;
- стовпчиковий графік для порівняння областей;
- кнопка скидання фільтрів.

## Примітка

Дані не включені в репозиторій, якщо файл великий або генерується окремо. Для перевірки потрібно використати очищений CSV з попередньої лабораторної роботи.
